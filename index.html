Google Apps Script Web App

Hệ thống hỗ trợ kết nối trực tiếp với Google Apps Script gắn trên Google Sheets của bạn để lưu trữ vĩnh viễn và bảo mật:

👉 Cách tạo Google Sheet Web App riêng trong 1 phút (Bấm để xem hướng dẫn)

1. Mở một Google Sheet mới $\rightarrow$ Vào menu Tiện ích mở rộng (Extensions) $\rightarrow$ Apps Script.

2. Dán đoạn mã sau vào rồi bấm Triển khai (Deploy) $\rightarrow$ Tùy chọn triển khai mới (New deployment):

function doGet(e) {
  var data = PropertiesService.getScriptProperties().getProperty('KFM_RECON') || '{}';
  return ContentService.createTextOutput(data).setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  var data = e.postData.contents;
  PropertiesService.getScriptProperties().setProperty('KFM_RECON', data);
  return ContentService.createTextOutput(JSON.stringify({status:'ok'})).setMimeType(ContentService.MimeType.JSON);
}

3. Chọn quyền truy cập: Bất kỳ ai (Anyone) $\rightarrow$ Bấm Deploy $\rightarrow$ Sao chép đường link Web App URL dán vào ô bên trên $\rightarrow$ Bấm Lưu URL là xong!
